# michael-jin-plastering-preview

Spec preview by [Crom Services](https://cromservices.com.au). Not the live site. Not indexed.

Public preview (GitHub Pages): https://cromservices.github.io/michael-jin-plastering-preview/

Five static pages at the repo root (`index.html`, `services.html`, `about.html`, `quote.html`, `contact.html`) plus `css/`, `fonts/`, `robots.txt`, and `sitemap.xml`. `wp-theme/` holds `theme.json` and block patterns for a later self-hosted WordPress port. The quote form is demo-only: it never POSTs.

`brief/` is the v1.2 wireframe pack. It is not linked from the site nav.
